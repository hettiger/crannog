# 0003. English-only repository

- **Status:** Accepted
- **Date:** 2026-10-30

## Context

crannog is open source and should be accessible to an international audience.

## Decision

Everything in the repository is written in English: code, identifiers,
comments, docs, commit messages, PR and issue texts, CLI output and help texts.

## Alternatives

None evaluated.

## Consequences

Discussions may happen in other languages, but their results are recorded in
English.
